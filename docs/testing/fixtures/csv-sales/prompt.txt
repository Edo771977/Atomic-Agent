Build an offline Node.js CSV sales summarizer as a fusion project, with the program and its tests as two separate worker tasks. The program is sales.cjs in this folder: CommonJS, Node built-ins only, no network and no dependencies, run as `node sales.cjs <input.csv>`. The first line of the input must be exactly sku,qty,price_cents (a trailing carriage return is allowed); otherwise print an error containing "Invalid header" to stderr, print nothing on stdout and exit 1. Every later non-blank line has exactly three comma-separated fields: a non-empty sku, then qty and price_cents as non-negative whole numbers written in decimal digits only. For any other row (a negative, fractional, non-numeric or missing number, or the wrong number of fields) print an error containing "Invalid row" and its line number to stderr, print nothing on stdout and exit 1. On success print one JSON object on stdout that maps each sku to its total revenue in cents (the sum of qty times price_cents over its rows, an integer; any sku text must work, including toString and __proto__) and exit 0; a total beyond Number.MAX_SAFE_INTEGER is an invalid row. The tests are sales.test.cjs, run with `node --test sales.test.cjs`, and cover repeated skus, zero values, a sku named toString, a wrong first line with no valid header before it, and invalid numbers. Run `node --test sales.test.cjs` and get the configured reviewer's verdict on each task before you report the milestone.
